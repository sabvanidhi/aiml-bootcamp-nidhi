# Loan Approval Analysis

**CodeTrade AI/ML Internship — Phase 1 Capstone**

## Project Overview

This project analyzes loan application data to identify which applicant characteristics are associated with loan approval.

**Research Question:** Which applicant characteristics are most strongly associated with loan approval?

## Dataset

* Total applications: 614
* Total columns: 13
* Target variable: `Loan_Status`

## Tools Used

Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy, and Jupyter Notebook.

## Key Findings

* **Credit History:** Applicants with `Credit_History = 1` had a higher number of approvals than rejections.
* **Applicant Income:** The t-test returned a p-value of approximately 0.84015, showing no statistically significant difference in mean income between approved and rejected applicants.
* **Education:** The median income was similar across the approval groups.
* **Applicant Income and Loan Amount:** A positive correlation of approximately 0.303 was observed.

## Conclusion

Credit History showed a clear association with loan approval in this dataset. However, Applicant Income alone did not show a statistically significant difference between approved and rejected applicants.

This project provided practical experience in data cleaning, exploratory data analysis, statistical hypothesis testing, and data visualisation using Python.

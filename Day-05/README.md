# Day 05 - Student Utilities

## What this module does

`log_utils.py` provides functions for calculating student performance statistics.

It can calculate:

- Average marks
- Pass rate
- Highest mark
- Lowest mark
- Class average and pass rate together

The module uses type hints and Google-style docstrings.
